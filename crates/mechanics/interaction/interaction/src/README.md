# Interaction System

This module handles all the interactions created over the platform. The user is cappable to hold a button to interect, tap to interact.

The dev has full controll over the interaction, using events like `On<InteractionStart<T>>`, `On<InteractionOnGoing<T>>` , `On<InteractionEnd<T>>`.

With that, the user can track anything he wants over all collactables and interactable items.
